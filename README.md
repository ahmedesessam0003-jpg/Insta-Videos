# تحميل فيديوهات المنتجات من إنستجرام

سكربت بايثون يفحص كل منشورات حساب إنستجرام (افتراضياً [naturalroots.store](https://www.instagram.com/naturalroots.store/))
ويحمّل **الفيديوهات فقط** التي يذكر وصفها أحد المنتجات، ثم يحفظ كل فيديو داخل مجلد المنتج الخاص به وباسم المجلد نفسه.

## ماذا يفعل بالضبط؟

- **يكفي جزء من اسم المنتج في الوصف**: مثلاً «الوسمة» أو «بخاخ الشعر» أو «ماسك البروتين» أو «معجون الحنة» أو «بودرة السدر».
  الكلمات الخاصة بكل منتج موجودة في `products.json` ويمكنك تعديلها.
- البحث لا يتأثر بالتشكيل (الحنّة = الحنة) ولا بـ ة/ه أو أ/ا أو ى/ي، ويتعرف على الهاشتاج (`#معجون_الحنة`)
  وعلى الحروف المتصلة مثل «والوسمة» و«بالوسمة» و«للشعر».
- **اسم الملف = اسم مجلد المنتج**. إذا كان للمنتج أكثر من فيديو تُرقَّم الفيديوهات حسب تاريخ النشر:
  ```
  معجون الحنّة الطبيعي بالقسط الهندي والبلميط المنشاري وزيت نواة التمر (1).mp4
  معجون الحنّة الطبيعي بالقسط الهندي والبلميط المنشاري وزيت نواة التمر (2).mp4
  ```
  وإذا كان للمنتج فيديو واحد فقط يُحفظ بدون رقم.
- الألبومات (Carousel) التي فيها أكثر من فيديو: يُحمَّل كل فيديو منها برقم مستقل.
- إذا ذُكر أكثر من منتج في نفس الوصف يذهب الفيديو إلى **أول منتج مذكور** (يمكن تغيير ذلك، انظر `match_mode`).
- إذا كانت مجلدات المنتجات موجودة عندك بالفعل، يستخدمها السكربت ويأخذ أسماءها كما هي بالضبط
  (حتى لو اختلف التشكيل أو ة/ه عن `products.json`). والمجلد غير الموجود يُنشأ تلقائياً.
- عند إعادة التشغيل يحمّل **الجديد فقط**، ويعيد الترقيم تلقائياً إذا لزم (مثلاً منتج كان له فيديو واحد ثم نُشر له فيديو ثانٍ).
- **لا يحذف ولا يستبدل أي ملف لم ينشئه السكربت** داخل مجلدات المنتجات.
- في نهاية كل تشغيل يكتب تقريراً `videos_report.csv` (يُفتح بالإكسل) داخل مجلد المنتجات: كل منشور فيديو،
  وهل طابق منتجاً، وبأي كلمة، واسم الملف، ووصف المنشور. الفيديوهات التي لم تطابق أي منتج تظهر فيه أيضاً
  لتضيف لها كلمات بحث إن احتجت.

## التثبيت (مرة واحدة)

1. ثبّت **Python 3.9 أو أحدث** من [python.org](https://www.python.org/downloads/)
   وفعّل خيار **Add python.exe to PATH** أثناء التثبيت.
2. حمّل المشروع (زر **Code** ثم **Download ZIP**) وفك الضغط.

**على ويندوز:** اضغط مرتين على `run.bat`، فيثبّت المتطلبات تلقائياً ثم يشغّل السكربت.

أو يدوياً من سطر الأوامر:

```
pip install -r requirements.txt
python insta_videos.py
```

## الإعداد: ملف `products.json`

| الإعداد | المعنى |
|---|---|
| `profile` | حساب إنستجرام (`naturalroots.store`) |
| `output_dir` | **المجلد الذي بداخله مجلدات المنتجات**، مثال: `"D:/Natural Roots/المنتجات"` (استخدم `/` في المسار) |
| `products` | لكل منتج: `name` (اسم المجلد) و`keywords` (الكلمات التي تكفي لمطابقة الوصف) |
| `match_mode` | `"first"`: الفيديو لأول منتج مذكور في الوصف (الافتراضي). `"all"`: نسخة في مجلد كل منتج مذكور |
| `number_format` | شكل الترقيم، الافتراضي `"{name} ({n})"`، ويمكن مثلاً `"{name} {n}"` أو `"{name} - {n}"` |
| `exclude_posts` | روابط منشورات لا تريد تحميلها أبداً، مثال: `["https://www.instagram.com/p/ABC123/"]` |

إضافة منتج جديد: أضف عنصراً جديداً بنفس الشكل في `products`. إذا لم تكتب `keywords` تُستخدم أول كلمتين من الاسم.

## تسجيل الدخول لإنستجرام (مهم)

إنستجرام حالياً لا يسمح بقراءة الحساب بدون تسجيل دخول، والطريقة التي تعمل هي **ملف الكوكيز**:

### الطريقة 1 (المفضلة): ملف `cookies.txt`

1. افتح [instagram.com](https://www.instagram.com) في المتصفح وسجّل الدخول.
2. ثبّت إضافة **Get cookies.txt LOCALLY** (لكروم وإيدج) أو **cookies.txt** (لفايرفوكس).
3. وأنت على صفحة إنستجرام اضغط على الإضافة ثم **Export**، واحفظ الملف باسم `cookies.txt` بجانب `insta_videos.py`.

السكربت سيجده ويستخدمه تلقائياً. ملفات JSON المصدَّرة من إضافة Cookie-Editor مدعومة أيضاً (احفظها باسم `cookies.json`).

> ⚠️ ملف الكوكيز يعادل كلمة السر: لا ترسله لأحد (وهو مستثنى من git في هذا المشروع).
> وإذا ظهرت رسالة بأن الكوكيز غير صالحة، سجّل الدخول في المتصفح من جديد وصدّر الملف مرة أخرى.

### الطريقة 2: القراءة من المتصفح مباشرة

```
python insta_videos.py --browser firefox
```

فايرفوكس هو الأضمن. كروم الحديث على ويندوز يشفّر الكوكيز فقد لا تنجح معه، فاستخدم الطريقة 1.

### الطريقة 3: اسم المستخدم وكلمة السر

```
python insta_videos.py --login اسم_المستخدم
```

تُطلب كلمة السر (وكود التحقق الثنائي إن وجد) مرة واحدة فقط، ثم تُحفظ الجلسة للمرات القادمة.
قد يطلب إنستجرام تأكيد محاولة الدخول من التطبيق.
هذه الطريقة تعمل بمكتبة instaloader فقط، وهي حالياً مرفوضة من إنستجرام (انظر الفقرة التالية)، لذلك استخدم ملف الكوكيز.

## طريقة قراءة إنستجرام (`--backend`)

السكربت يقرأ الحساب بإحدى مكتبتين، ويختار تلقائياً (`auto`، الافتراضي):

- **مع ملف الكوكيز**: يستخدم **gallery-dl**. وإذا لم يصل لأي منشور بها يجرّب instaloader تلقائياً.
- **بدون كوكيز** (أو مع `--login`): يستخدم **instaloader** فقط.

> ملاحظة (سبتمبر 2026): إنستجرام يرد على instaloader بالخطأ `429 Too Many Requests` من أول طلب،
> حتى مع تسجيل الدخول الصحيح. هذا ليس حظراً بسبب كثرة الطلبات، والانتظار لا يحله.
> لذلك يتوقف السكربت فوراً مع رسالة توضيحية بدل الانتظار، بينما gallery-dl مع الكوكيز يعمل.

لفرض طريقة معينة: `--backend gallery-dl` أو `--backend instaloader`.

## التشغيل

```
python insta_videos.py --dry-run                       # تجربة: يعرض ما سيحدث ويكتب التقرير بدون تحميل
python insta_videos.py                                 # التحميل
python insta_videos.py --out "D:\Natural Roots\المنتجات" # مجلد منتجات مختلف عن output_dir
python insta_videos.py --reels                         # فحص تبويب الريلز أيضاً (للريلز غير الظاهرة في الصفحة الرئيسية؛ أبطأ)
python insta_videos.py --max-posts 20                  # فحص أحدث 20 منشور فقط (تجربة سريعة)
python insta_videos.py --match all                     # نسخة من الفيديو في مجلد كل منتج مذكور في وصفه
python insta_videos.py --backend instaloader           # فرض طريقة قراءة معينة بدل الاختيار التلقائي
```

من `run.bat` يمكن تمرير نفس الخيارات، مثال: `run.bat --dry-run`. وكل الخيارات تظهر بـ `python insta_videos.py --help`.

يُنصح بالتجربة أولاً بـ `--dry-run` ومراجعة `videos_report.csv`، ثم التشغيل الفعلي.

## حل المشاكل

| المشكلة | الحل |
|---|---|
| رسالة فيها `401` أو `login` أو `redirect` | إنستجرام يطلب تسجيل الدخول: صدّر ملف الكوكيز من جديد (انظر أعلاه) |
| `429` مع instaloader من أول طلب (`web_profile_info`) | ليس حظراً والانتظار لا يحله: ضع ملف الكوكيز `cookies.txt` بجانب السكربت وشغّله بدون `--backend instaloader`، فيستخدم gallery-dl |
| `429` أثناء الفحص أو `Please wait a few minutes` | أوقف إنستجرام الطلبات مؤقتاً: انتظر من نصف ساعة لساعة ثم أعد التشغيل، وسيكمل السكربت من حيث توقف |
| `Checkpoint` أو `challenge` | افتح إنستجرام من المتصفح أو التطبيق وأكّد أنك أنت، ثم أعد المحاولة |
| لا تعمل أي طريقة | حدّث المكتبات: `pip install -U -r requirements.txt` (يفعلها `run.bat` تلقائياً)، ثم صدّر الكوكيز من جديد |
| فيديو دخل مجلداً خاطئاً | اجعل كلمات المنتج أدق في `keywords`، أو ضع رابط المنشور في `exclude_posts` واحذف الملف |
| فيديو لم يُحمَّل | ابحث عنه في التقرير («لا يطابق أي منتج») وأضف كلمة من وصفه إلى كلمات المنتج المناسب |
| «تعذرت إعادة تسمية» | أغلق أي برنامج يفتح الفيديو ثم أعد التشغيل |

## ملاحظات

- لا تحذف الملف `.insta-videos-state.json` الموجود داخل مجلد المنتجات: به يتذكر السكربت ما حمّله ليكمل ويعيد الترقيم بأمان.
- إذا حذفت فيديو حمّله السكربت فسيُعاد تحميله في التشغيل القادم، إلا إذا أضفت رابط منشوره إلى `exclude_posts`.
- لا تشغّل السكربت مرات كثيرة متتالية حتى لا يوقف إنستجرام الحساب مؤقتاً.
- لتشغيل الاختبارات: `python -m unittest discover tests`
